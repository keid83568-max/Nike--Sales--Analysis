# Nike Sales Analysis Project 👟

## 📊 Overview
This project provides a comprehensive analysis of Nike's sales performance. Using SQL for data cleaning and Power BI for visualization.

## 🛠️ Tools Used
* **SQL:** Data cleaning & Transformation.
* **Power BI:** Interactive Dashboard & Insights.
* **Excel:** Source data handling.
